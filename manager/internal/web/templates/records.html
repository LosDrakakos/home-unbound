Add a record

A record: enter an IPv4 address, for example 192.168.1.10.

AAAA record: enter an IPv6 address, for example fd00::10.

CNAME record: enter the canonical hostname, for example nas.home.arpa.

TXT record: printable ASCII only; quotes and backslashes are rejected.

PTR name: use 192.168.1.10 or 10.1.168.192.in-addr.arpa; value is the target hostname.

MX fields

Lower preference values are tried first.

SRV fields

Use a service owner such as _sip._tcp.home.arpa.
